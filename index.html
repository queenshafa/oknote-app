Oknote? What is that?

Oknote is a minimalist calendar-based notes application designed to help users organize their daily activities with ease. It allows users to add quick notes, set time ranges, choose highlight colors, and view all schedules directly inside the calendar. Each note is stored locally using localStorage, ensuring data stays saved even after refreshing the page.
